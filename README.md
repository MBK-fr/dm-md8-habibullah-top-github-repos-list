## 🤖 AI & LLM Engineering (TOP PRIORITY) — The "New" Essential

**⭐ This is THE fastest-growing category on GitHub. Curated for 2026.**

### 🎯 Large Language Models (LLM) & Model Running

* [Ollama](https://github.com/ollama/ollama) — ⭐ **65k+ stars** — Run LLMs locally (Llama 3.2, Mistral, Hermes, Neural Chat, Orca, etc.) — dead simple inference.
* [LM Studio](https://github.com/lmstudio-ai/lm-studio) — Desktop app to discover, download, and run local LLMs with a beautiful UI.
* [GPT4All](https://github.com/nomic-ai/gpt4all) — ⭐ **68k+ stars** — Run open-source LLMs offline on your machine (no internet, privacy-first).
* [Vllm](https://github.com/vllm-project/vllm) — High-throughput LLM inference server, dramatically faster than standard implementations.
* [text-generation-webui](https://github.com/oobabooga/text-generation-webui) — A Gradio web UI for running LLMs with advanced sampling and tuning options.
* [LocalAI](https://github.com/mudler/LocalAI) — OpenAI API-compatible local inference engine supporting multiple models.
* [Hugging Face Transformers](https://github.com/huggingface/transformers) — ⭐ **130k+ stars** — State-of-the-art ML for PyTorch, TensorFlow, and JAX. The standard for NLP.
* [Anthropic Claude (Official SDKs)](https://github.com/anthropics/anthropic-sdk-python) — Official Claude AI SDK for Python, JavaScript, and more.

### 🛠️ LLM Application Frameworks (Build Products)

* [LangChain](https://github.com/langchain-ai/langchain) — ⭐ **80k+ stars** — **THE** standard for building LLM-powered applications with memory, agents, and retrieval.
* [Llama Index (formerly GPT Index)](https://github.com/run-llama/llama_index) — Data indexing and retrieval framework for LLMs. Query your documents with AI.
* [LangGraph](https://github.com/langchain-ai/langgraph) — Build resilient, multi-step AI applications using LLMs with state management and human-in-the-loop.
* [CrewAI](https://github.com/joaomdmoura/crewai) — AI agent orchestration framework for building collaborative AI teams (agents with roles and tasks).
* [AutoGen](https://github.com/microsoft/autogen) — Multi-agent conversation framework for building complex AI workflows with message passing.
* [Dify](https://github.com/langgenius/dify) — ⭐ **42k+ stars** — Open-source platform for building and deploying LLM apps visually (no-code/low-code).
* [Vercel AI SDK](https://github.com/vercel/ai) — Build AI applications with JavaScript/TypeScript, supporting multiple AI providers.
* [Semantic Kernel](https://github.com/microsoft/semantic-kernel) — MS framework for building semantic applications combining LLMs with plugins.

### 🧠 Model Fine-Tuning & Training

* [Hugging Face peft](https://github.com/huggingface/peft) — Parameter-efficient fine-tuning (LoRA, QLoRA, etc.) for LLMs.
* [Unsloth](https://github.com/unslothai/unsloth) — 2-5x faster LLM fine-tuning with memory efficiency. Dramatically accelerates training.
* [Axolotl](https://github.com/OpenAccess-AI-Collective/axolotl) — Simplified fine-tuning framework for open-source LLMs.
* [TRL (Transformer Reinforcement Learning)](https://github.com/huggingface/trl) — Tools for RLHF (Reinforcement Learning from Human Feedback) training.
* [LitGPT](https://github.com/Lightning-AI/litgpt) — Hackable implementation of open-source LLMs with training and inference.

### 🤖 AI Agents & Automation

* [Browser-use](https://github.com/browser-use/browser-use) — ⭐ **16k+ stars** — Let AI agents autonomously use web browsers, fill forms, scrape data, and automate workflows.
* [Aider](https://github.com/aider-chat/aider) — AI pair programming in your terminal. Aider can read your entire codebase and help you code faster.
* [Cursor](https://github.com/getcursor/cursor) — The AI code editor built on VSCode (uses Claude/GPT-4 for intelligent coding).
* [Dorothy](https://github.com/Charlie85270/Dorothy) — Desktop app to orchestrate multiple AI CLI agents simultaneously with Kanban-style task management.
* [GPT Researcher](https://github.com/assafelovic/gpt-researcher) — Autonomous research agent that conducts online research and compiles comprehensive reports.
* [Open Interpreter](https://github.com/KillianLucas/open-interpreter) — Natural language interface for running code on your computer. Ask AI to do anything.
* [Anthropic Code Claude](https://github.com/anthropics/claude-code) — Agentic coding tool that understands your codebase and provides intelligent suggestions.

### 💬 AI Chat & RAG Systems

* [Quivr](https://github.com/QuivrHQ/quivr) — Second brain for your documents. Upload files and chat with them using AI (RAG).
* [Anything LLM](https://github.com/Mintplex-Labs/anything-llm) — Private ChatGPT with document support. Run locally, all your data stays yours.
* [Flowise](https://github.com/FlowiseAI/Flowise) — Visual builder for LLM applications (drag-and-drop workflows).
* [Chroma](https://github.com/chroma-core/chroma) — AI-native vector database for building semantic search and RAG systems.
* [Weaviate](https://github.com/weaviate/weaviate) — Open-source vector database for ML-powered search and similarity.
* [Milvus](https://github.com/milvus-io/milvus) — High-performance vector database for AI applications (built by Zilliz).

### 🎨 Open-Source LLMs & Models

* [Llama 2 / Llama 3](https://github.com/meta-llama/llama) — Meta's open-source LLMs (Llama 3 is competitive with closed models).
* [Mistral AI](https://github.com/mistralai/mistral-common) — Fast, efficient open-source LLM with 7B, 8x7B, and more variants.
* [Hermes 3](https://github.com/NousResearch/Hermes-3) — High-quality instruction-tuned model, excellent for function calling.
* [Orca](https://github.com/microsoft/orca) — Microsoft's model trained via imitation learning for reasoning.
* [Stable Diffusion (Text-to-Image)](https://github.com/CompVis/stable-diffusion) — ⭐ **60k+ stars** — Open-source image generation model.
* [Whisper (Speech-to-Text)](https://github.com/openai/whisper) — ⭐ **65k+ stars** — Open-source speech recognition by OpenAI.
